## 2. Описание (до 4000 символов)

```
AniTV — неофициальный клиент сервиса AniLiberty для Apple TV: каталог, избранное и просмотр аниме на
большом экране, с нативным интерфейсом tvOS и управлением только пультом.

ЧТО ВНУТРИ

• Главная с двумя подборками: свежие серии и обновления в вашем избранном.
• Поиск по названию и каталог с фильтрами по жанру, типу, году и сортировке.
• Карточка релиза: описание, рейтинг, список серий, выбор озвучки и качества.
• Плеер на системном AVPlayer: продолжение с места остановки, автоматический пропуск опенингов и
  эндингов по желанию, переключение качества прямо в панели плеера.
• Избранное и профиль: привязка телевизора по коду — без ввода пароля пультом.

КАК ЭТО РАБОТАЕТ

Приложение обращается к открытому API сервиса AniLiberty. Аккаунт нужен только для избранного и профиля:
каталог, поиск и просмотр доступны без входа. Привязка телевизора выполняется кодом: он показан на
экране, вводится на сайте сервиса, пароль на пульте не набирается.

ЧЕГО ПРИЛОЖЕНИЕ НЕ ДЕЛАЕТ

Не собирает данные, не показывает рекламу, не содержит аналитики и сторонних библиотек.

ВАЖНО

Приложение не является официальным клиентом AniLiberty и не связано с его правообладателями. Доступность
каталога и воспроизведение зависят от самого сервиса и вашего аккаунта в нём.

Требуется tvOS 27 или новее.
```

## 5. TestFlight

**What to test** (показывается тестерам):

```
Проверьте, пожалуйста:
1. Главную: карусели «Новинки» и «Обновления в избранном» (вторая — только после привязки аккаунта).
2. Поиск и каталог: фильтры по жанру, типу, году, сортировке, «Показать ещё».
3. Карточку релиза и плеер: продолжение с места остановки, пропуск опенинга/эндинга, смена качества.
4. Навигацию пультом: сайдбар, возврат назад, переключение разделов.
Кнопки «Назад» и «Menu» должны всегда возвращать туда, откуда пришли. Ошибки и странности — в Issues.
```

**Test Information → Feedback / contact:** ссылка на Issues репозитория.

**App Review Information (важно):**

```
Приложение не требует входа для проверки: главная, поиск, каталог, карточка релиза и плеер работают без
аккаунта. Привязка аккаунта нужна только для избранного и профиля; она выполняется кодом, который
показывает телевизор, и вводится на aniliberty.top — пароль в приложении не вводится.

AniTV — неофициальный клиент сервиса AniLiberty, не связан с его правообладателями и не содержит
собственного контента: приложение показывает каталог и воспроизводит потоки сервиса, доступ к которым
определяется аккаунтом пользователя.
```

Если Apple попросит тестовый аккаунт — его нужно создать и указать в этой форме (заводится владельцем,
не хранится в репозитории).

## 6. Публикация политики конфиденциальности

Нужен публичный URL. Самый дешёвый путь — GitHub Pages из этого же репозитория:

1. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/docs`.
2. Через минуту политика будет доступна как
   `https://vetalpros.github.io/AniTV/PRIVACY` (имя файла — `docs/PRIVACY.md`).
3. Этот адрес вставляется в **Privacy Policy URL**.

До слияния ветки в `main` страница будет отдавать старую версию `docs/` — публиковать имеет смысл после PR.
